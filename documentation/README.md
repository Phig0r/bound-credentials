This PDF predates the repository's Bound Credentials naming and documentation cleanup. It has not been regenerated or peer reviewed. Treat it as a technical report from an earlier design revision; use the root README, current contracts, and tests for current behavior and limitations. In particular, do not interpret identity-binding or authenticity language as proof of a unique person or a genuine qualification.

Some diagrams and mockups show earlier design revisions. Both class-diagram versions are retained as design history. The live UI and source may differ. Diagram editor recovery files are excluded from Git.
