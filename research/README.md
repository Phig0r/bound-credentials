# Bound Credentials technical report

[Read the technical report (PDF)](Bound-Credentials-Technical-Report.pdf).

This is a project technical report, not a peer-reviewed publication. Its filename now follows the same convention as Private Airdrop and Provenance. The PDF itself has not been recompiled and may use the former project name and earlier design language.

For current behavior, read the [repository overview](../README.md) and contracts. In particular, non-transferability does not establish a unique person or a real qualification; the demo faucet grants public privileges, and on-chain certificate details are public. Earlier identity or authenticity language must be read within those boundaries.

Supporting [diagrams and interface mockups](../documentation/README.md) are kept separately. There is only one report PDF in this repository.
